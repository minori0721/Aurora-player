# Aurora Player（极光播放器）

**当前版本：v0.1.4**

在线体验：[music.moerika.com](https://music.moerika.com/) · [备用站点](https://player.minori0721.dpdns.org/)

纯前端音乐播放器，支持本地音频、网易云音乐、同步歌词和精确循环。源码按职责拆分，构建后仍是一个包含脚本、样式、Worker 和固定版本前端库的 `index.html`。

听歌之外，也可以拿来循环播放游戏 BGM，配上 `.sli` 循环点和 `.lrc` 歌词。

## 核心功能

- **本地播放**：导入音频文件或文件夹，读取内嵌标签、封面及配套 LRC；可恢复播放列表中的曲目信息。
- **网易云音乐**：搜索歌曲、专辑和歌手，互相跳转浏览，导入歌单，扫码或短信验证码登录，并下载账号可用的音质。
- **双播放方式**：在线播放默认流式优先，也可选择完整加载；流式失败时尝试完整加载兜底，设置会记住。
- **歌词**：支持普通与逐字歌词、翻译和罗马音，以及滚轮、触摸浏览、点击跳转和回到当前。
- **循环工具**：列表、随机与单曲循环，自定义 A/B、SLI 自动配对、循环点分析与导出。
- **界面与控制**：手机、平板和桌面布局，播放列表搜索、封面配色流动背景，以及「凛冬飞雪」「律动频谱」「极光波浪」；也可关闭特效，回到「纯净模式」。支持键盘和系统媒体控制。

## 本版变化

- 歌词原文、逐字数据、翻译和罗马音统一对齐，减少重复句、拆句和附属文本错位；无法可靠匹配时保留普通歌词，不猜测修改歌词内容。
- 切换「词／译／音」复用同一组主歌词行，保留逐字时间节点与当前定位。
- 手机端「流式播放／完整播放」对齐进度条中心，音质标签保持完整单行，过长时省略显示。
- Android 支持时优先打开系统文件选择器，允许音频、LRC 和 SLI 多选；取消不影响播放，选择器失败后再次点击可使用兼容方式。

完整版本记录见 [changelog.md](changelog.md)。

## 快速开始

### 下载单文件

从 [Releases](https://github.com/minori0721/Aurora-player/releases) 下载 `index.html`，可直接打开，也可放到静态主机。

本地播放不依赖网易云 API；在线搜索、登录、播放和下载需要可用的后端服务。

### 从源码运行

使用 Node.js 22 或 24，在仓库目录运行：

```sh
npm ci
npm run build
npm run dev
```

构建产物是 `dist/index.html`。开发服务会输出 `127.0.0.1` 地址，修改源码后刷新查看；只想直接打开文件时，运行构建后打开该产物即可。

Cloudflare Workers、Cloudflare Pages、Vercel 和 GitHub Pages 的设置见 [部署指南](docs/deployment.md)。日常修改 `src/`，不要手动修改 `dist/`。

## 使用须知

- **导入替换**：导入包含音频的新批次会替换当前播放列表；仅导入 SLI/LRC 时补充当前列表。
- **本地恢复**：保存曲目信息不等于保存音频文件。重新打开后，可能需要授权读取或重新选择文件；SLI/LRC 正文不随列表保存。
- **流式与循环**：浏览器可能回收流式缓冲；无缝单曲循环、A/B 和智能分析需要完整音频，可能重新传输并增加内存占用。
- **格式与权限**：能否解码取决于浏览器；在线音质、登录及下载还取决于 API、账号权益和音源，不保证每首都有无损或 Hi-Res。
- **隐私**：登录凭据保存在当前站点的浏览器存储中。公开构建配置只填服务地址，不要放入 Cookie、Token 或密钥。
