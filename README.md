# 🎵 Aurora Player (极光播放器)

**当前版本：v0.0.8**

**在线体验**：[https://music.moerika.com/](https://music.moerika.com/)
或：[https://player.minori0721.dpdns.org/](https://player.minori0721.dpdns.org/)

> 基于 Web Audio API 的单文件音乐播放器，支持本地音频、A/B 与 SLI 循环，以及网易云音乐搜索、浏览和播放。

## ✨ 项目简介

**Aurora Player** 是一个纯前端音乐播放器。开发源码按职责放在 `src/`，构建后只发布一个 `index.html`，包含样式、播放器代码和两个固定版本的前端库。音频通过浏览器的 `AudioContext` 解码，再使用 `AudioBuffer` 播放。

本地模式可用于播放游戏 BGM、设置循环点和读取配套歌词；网易云模式提供搜索、歌曲/专辑/歌手浏览、歌单导入与播放。本地播放不需要在线 API，网易云功能和下载代理则依赖另外部署的后端服务。

## 🚀 核心功能

### ☁️ 网易云音乐

通过配置的网易云音乐 API 提供以下功能：

* **音乐内容浏览器**：点击「☁️ 云音乐」即可按综合、歌曲、专辑和歌手分类搜索，并在歌曲、专辑、歌手之间直接跳转。
* **专辑与歌手页面**：专辑页展示接口返回的曲目，并提供顺序/随机播放和收藏；歌手页提供简介、热门歌曲、全部歌曲、专辑/EP、MV 和关注。MV 点击后打开网易云官方页面，不在播放器内播放视频。
* **浏览历史与上下文队列**：支持页面前进/后退、深链接和搜索状态恢复；从专辑或歌手页面播放时会自动建立对应队列。分页内容使用当前页的歌曲，不代表加载歌手的全部作品到队列。
* **音频下载**：支持下载歌曲文件。打开下载窗口时会按需读取歌曲音质详情，并检测 **标准 (128k) / 较高 (192k) / 极高 (320k) / 无损 (FLAC) / Hi-Res** 等选项；实际可用音质取决于歌曲、账号权益和接口返回，不保证每首都有无损或 Hi-Res。
* **账号登录**：支持 **APP 扫码登录**，加载「我创建的歌单」和「我收藏的歌单」，并提供专辑收藏、歌手关注等操作。登录不等于获得 VIP 权益，高音质与下载仍取决于账号权限和音源可用性。
* **歌单导入**：支持粘贴网易云歌单链接或 ID。系统先读取完整 `trackIds`，再按安全批次请求歌曲详情；首批歌曲加载后即可先导入播放，剩余歌曲会在后台按原顺序继续追加。加载过程中可以取消，快速切换歌单时旧请求不会混入新歌单。
* **下一首预加载**：网易云完整音频通常在剩余约 15 秒时开始下载，文件不小于 16 MiB 或大小未知时提前到约 25 秒；本地文件保持约 10 秒。在线 URL 可提前预热，正式播放会接管同一个下载任务；在线预取阶段不解码音频。
* **本地歌曲匹配**：启用网易云歌词搜索时，会优先把本地文件的标题、专辑、歌手和秒级时长交给 `/search/match`；当前实现不额外计算 MD5，接口无结果或不可用时自动回退综合搜索，不阻塞本地播放。
* **歌词显示模式**：支持 **仅原文 / 原文+翻译 / 原文+罗马音** 切换；翻译和罗马音需要歌词源提供对应内容。
* **逐字同步歌词**：接口返回逐字歌词 (YRC) 时，按时间轴显示逐字高亮；没有逐字数据时使用普通歌词。

### 🎧 音频播放

* **音频格式**：可导入 MP3、FLAC、OGG、WAV、M4A 等音频文件，实际能否播放取决于浏览器对文件编码的解码支持，不是支持所有编码的独立解码器。
* **按需渲染**：暂停且关闭视觉特效时停止动画帧；普通播放以较低频率刷新时间和歌词，视觉特效开启后恢复流畅绘制，页面隐藏时暂停视觉任务。关闭特效、隐藏页面或启用减少动态效果时，特效画布退出页面合成并缩为 `1×1`；恢复时在绘制前重建，保留原有像素密度。
* **结构化播放列表恢复**：在线歌曲、本地歌曲元数据和当前索引保存到 IndexedDB 的 `player-state` 存储区，并通过 `localStorage` 保留轻量恢复快照，不再从显示文本反推歌名；旧版 schema 2 和旧 `localStorage` 数据会自动迁移。浏览器支持文件句柄时会尝试恢复本地文件，否则只需重新选择文件即可继续播放。
* **无缝循环 (Seamless Loop)**：单曲循环直接在 Web Audio 音频线程内按 `0 → duration` 回跳；启用 A/B 或 `.sli` 后则按自定义采样点循环，不需要重新请求或解码歌曲。
* **文件夹递归导入**：可以直接拖入包含音频、`.sli` 和 `.lrc` 的目录，扫描完成后一次性生成播放列表。
* **SLI 自动配对**：读取 `.sli` 中的 `From` / `To` 循环点，可识别 `曲名.sli`、`曲名.wav.sli`、`曲名.ogg.sli` 和大小写混合扩展名，并按目录与文件名配对。
* **播放列表封面按需加载**：相同地址的封面共享加载任务与缓存结果，可同时服务多首歌曲；优先加载当前可见区域及前后约 300px 的歌曲，后台追加歌单时保留已有节点。失败重试、缓存淘汰或重新加载后仍可能再次请求。
* **切歌任务隔离**：本地文件读取、解码、在线音频和元数据等异步任务检查播放令牌或曲目身份，丢弃过期结果。

### 📱 响应式布局

* **多端布局**：提供手机、平板和桌面布局；部分文件权限、音频格式和系统媒体控制能力仍受浏览器与设备限制。
* **手势操作**：移动端支持底部面板滑出、触摸拖动进度条。
* **播放按钮比例**：桌面控制栏随可用宽度收窄间距与按钮尺寸，保持单行和圆形比例；兼顾 4:3 屏幕及手机布局切换边界。
* **键盘与无障碍**：主要移动端触点不小于约 44px，播放列表支持 Enter/Space；弹层会锁定背景、限制 Tab 焦点并在关闭后恢复原焦点。
* **自适应菜单**：
* 桌面端：显示完整工具栏。
* 移动端：自动折叠至「⚙️ 高级」菜单（包含 Debug、智能分析、循环设定、特效切换等）；顶部保留「导入」「高级」长条按钮，云音乐、下载和播放列表使用圆形图标按钮。



### 🔍 智能循环分析

* **三档匹配算法**：支持「速度优先 / 均衡推荐 / 准确优先」，可按歌曲复杂度和等待时间选择匹配策略。
* **循环点搜索**：根据粗略 A/B 点，在附近搜索候选接缝，结果建议试听确认；不保证任意歌曲或任意区间都能匹配成功。
* **后台分析**：优先使用 Web Worker 执行匹配；Worker 不可用时回退主线程，回退期间页面可能短暂卡顿。
* **分析内存**：Worker 使用独立的 mono 数据，不转移播放声道，也不额外保留主线程 mono 副本。最后一个任务完成后闲置 60 秒释放 Worker；再次分析会重新准备数据。主线程回退完成后释放临时分析缓存。
* **循环点导出**：支持将当前有效的循环区间导出为 `.sli` 文件。

### 🎨 界面与可视化

* **流体极光背景**：使用 `ColorThief` 生成封面调色板，结合颜色覆盖率选择主辅色，对黑白区域降权，再生成有明暗层次的四层动态渐变。纯黑白或灰色封面保持灰度；启用系统减少动态效果时停止背景动画。
* **动态特效**：内置多种 Canvas 可视化效果：
* ✨ **无特效** (纯净模式)
* ❄️ **凛冬飞雪** (随低音鼓点加速)
* 📊 **律动频谱**
* 🌊 **极光波浪**



## 📖 使用指南

### 方式一：本地播放 (文件与文件夹导入)

1. **文件支持**：直接将 `.mp3`, `.flac`, `.ogg`, `.wav`, `.m4a` 等音频文件或整个文件夹拖入窗口。
2. **递归扫描**：拖入文件夹时会读取其中的子目录，等扫描完成后再一次性导入，不会边扫描边播放。
3. **配套文件**：同批或后续补充的歌词 (`.lrc`) 与循环信息 (`.sli`) 会重新匹配整个播放列表，不再只作用于当前歌曲。
4. **批次规则**：包含音频的新批次会替换当前播放列表；只有 `.sli` / `.lrc` 的批次会补充当前列表。空列表时先导入的伴随文件会暂存到下一批本地音频。
5. **匹配状态**：成功绑定 SLI 的歌曲会在播放列表显示 `∞` 标记；导入后会显示音频、SLI、匹配、未匹配、歧义和无效数量。
6. **浏览器兼容**：优先使用标准文件系统接口，并兼容 Chromium/Safari 的旧目录接口；浏览器无法展开目录时会明确提示改为选择目录内文件。
7. **快捷键**：
* `Space`: 播放/暂停
* `← / →`: 快退/快进
* `↑ / ↓`: 音量调节

快捷键只在页面非交互区域生效。焦点位于输入框、按钮、选择器、进度条、链接或弹层内时，保留控件原生键盘行为。

本地播放列表恢复不等于保存音频文件：恢复时会使用最新列表与索引，并按路径、大小和修改时间从 IndexedDB 补回唯一匹配的文件句柄。支持文件句柄的浏览器中，重新打开后点击播放即可请求读取授权；已有授权时可直接读取，后台切歌不会自行弹出授权框。句柄已丢失、浏览器不支持或文件不可访问时，需要重新选择文件；旧版已经覆盖掉句柄的列表需重新拖入一次。SLI/LRC 文件正文不会随播放列表持久化；刷新后补充伴随文件时，会按恢复的目录与文件名重新安全配对，同名歧义仍不会自动绑定。

切歌仅保存带有列表身份和内容版本的选中位置，列表内容或元数据变化时才重新保存完整快照；恢复时忽略属于其他列表或旧内容版本的索引。IndexedDB 中的列表和索引在同一事务内读写，`localStorage` 继续保留无文件句柄的备用快照。浏览器存储被禁用、空间不足或进程被强制结束时，最后一次更新仍可能无法保存。



### 方式二：网易云在线模式

1. 点击顶部工具栏的 **「☁️ 云音乐」** 按钮打开面板。
2. **搜索与浏览**：输入关键词后可切换「综合 / 歌曲 / 专辑 / 歌手」，点击歌手名或专辑封面进入对应页面。
3. **连续播放**：从搜索结果、专辑或歌手页面选择歌曲后，播放器会使用当前页面内容建立队列；浏览器面板保持打开，底部迷你播放器可控制播放。
4. **历史导航**：页面地址使用 `#music/...` Hash 路由，可刷新、前进、后退或直接打开专辑与歌手深链接。关闭面板不会停止音乐，再次打开会恢复最后浏览位置。
5. **扫码登录**：点击「扫码登录网易云账号」，使用网易云 APP 扫码。登录后可读取账号歌单、收藏专辑和关注歌手；可用音质仍受账号权益与歌曲权限限制。
6. **歌单后台加载**：我的歌单会先显示首批结果，之后按 API 返回的 `more` 和 `offset` 在后台继续分页；歌单导入会读取完整 `trackIds`，按 `/song/detail` 批次补齐歌曲，并显示当前已加载数量，例如 `播放已加载 10/120 首`。信息请求及歌曲批次的超时覆盖响应正文读取。取消或退出账号后会保留已加载的歌曲，清除等待状态且不自动切歌；替换歌单后旧批次不能回填新列表。
7. **下载音乐**：播放歌曲时，点击控制栏右侧的 **下载图标** (⬇️)，选择可用音质进行下载。

音乐浏览器与下载窗口使用统一弹层行为：打开后背景不可操作，`Tab / Shift+Tab` 不会跳出弹层，`Escape`、关闭按钮和背景点击使用同一关闭流程。音乐浏览器根页的返回按钮只关闭面板，不会把 Aurora 页面退到 `about:blank`；浏览器前进仍可重新进入刚关闭的音乐页。

播放列表封面使用共享资源调度器：并发请求上限为 4，单次请求 8 秒超时，失败最多重试 2 次，连续失败后进入 30 秒冷却。关闭播放列表或快速替换歌单时，旧节点和旧请求不会回填到新列表；封面加载失败会保留占位状态，不会阻塞音频播放。

### 网易云 API 行为与边界

Aurora 通过 `api-enhanced` 的 HTTP 接口完成在线功能，其中账号相关接口需要登录，具体行为如下：

* **歌单详情**：优先使用 `/playlist/detail` 返回的 `trackIds` 作为歌曲顺序，再拆分请求 `/song/detail`，不只依赖详情接口中的部分 `tracks`。接口拒绝访问、缺失歌曲或部分批次失败时，仍可能只取得部分内容。
* **我的歌单**：使用 `/user/playlist` 的 `more`、`limit` 和 `offset` 分页，首屏先显示，后台继续补齐，并按歌单 ID 去重。
* **歌手页面**：歌手概览优先使用 `/artists?id=...` 一次获取歌手信息和热门歌曲；响应缺少字段时才回退 `/artist/detail` 与 `/artist/top/song`。概览会预取专辑和 MV 的前 30 项，但只展示前 6 项，进入对应标签的第一页时直接复用同一份缓存。
* **歌手页缓存与重试**：公共歌手、专辑、MV 和搜索结果使用统一的内存 + IndexedDB 缓存，失败响应不会写入缓存；概览的专辑或 MV 单独失败时只重试失败的资源，不会重复请求已经成功的部分。同一歌手切换标签时会复用相同 URL 的在途请求；跨歌手或跨实体切换时会取消旧导航，迟到响应不会覆盖当前页面。
* **本地匹配**：`/search/match` 的 `duration` 单位是秒；接口失败或没有可用候选时回退 `/cloudsearch`。有候选时按标题、歌手、专辑和时长评分选择，不保证一定匹配到同一版本的歌曲。当前不会为了匹配额外计算整首文件的 MD5。
* **音质详情**：只有打开下载窗口时才请求 `/song/music/detail`；各音质的大小、采样率和码率只用于展示，实际下载仍由现有下载接口和 match 兜底逻辑决定。
* **功能范围**：当前内容浏览器覆盖歌曲、专辑、歌手和 MV 外链；播客/声音页面以及 Aurora 内置 MV 播放器暂不在本版本范围内。

接口返回空结果、部分失败或账号权限不足时，播放器会尽量保留其他可用内容；需要登录的歌单、收藏、关注和高音质能力仍取决于网易云账号状态。

### 预加载与异常恢复

* 下一首在线音频预取上限通常为桌面 64 MiB、手机/低内存设备或慢速网络 32 MiB；这是预取限制，不是播放文件大小限制。API 已返回超限大小时只保留 URL；下载中发现超限也会停止读取正文。
* 本地文件保持提前 10 秒预读，并使用相同的 32/64 MiB 预算；超过上限跳过整文件预读，到正式播放时再读取，不限制可播放大小。超大文件切歌可能增加读取等待，同一目标不会重复尝试超限预读。
* 正式播放复用已完成的音频或接管进行中的预取，不因短暂等待而取消后重下。在线预取只保留压缩音频，到实际播放时才解码；当前播放仍需要整首解码，不能将这些上限理解为播放器总内存上限。
* URL 解析最长等待 30 秒，音频响应头最长等待 15 秒，正文连续 20 秒没有非空数据才判定停滞。持续传输的慢下载没有总时长限制；停滞恢复与失效 URL 刷新各最多一次，预取转正式播放不会重置重试额度，单纯停滞不会清除 URL 缓存。

### 离线依赖、缓存与隐私

* `jsmediatags 3.9.5` 与 `color-thief 2.4.0` 已连同许可证内嵌到 `index.html`，本地播放、标签读取和主题取色不再依赖运行时 CDN。
* 公共搜索、专辑和歌手元数据可进入 IndexedDB 缓存；包含 `cookie`、`token`、`key` 等凭据参数的请求只使用账号内存缓存，登录状态、二维码和账号修改不缓存。
* 公共缓存键会移除 `timestamp`、`noCache` 等瞬态参数。启动迁移和退出登录都会清理旧版含敏感参数的 IndexedDB 键。
* 在线音频链接遇到 `401 / 403 / 404 / 410` 时只清理对应缓存并强制重新解析一次；其他错误不会无条件清缓存或无限重试。
* 已解析音频链接的内存缓存最多保留 200 项，插入时清理过期项，访问命中的条目优先保留；淘汰后可能需要重新解析链接。
* 当前封面由主图、迷你播放器和 Media Session 共用显示地址。网易云图片按显示尺寸与 DPR 请求 512/768/1024/1536/2048px 的合适缩略图，窗口变化后延迟更新，不修改原始歌曲元数据；GIF/APNG/WebP 扩展名的图片保留原地址。缩略图尺寸变化可能增加一次图片请求，高倍率超过最大档位时可能损失细节。
* 本地封面保留原始 Blob，不新增解码、缩图或重编码步骤。切换资源后撤销旧 Blob URL，清空播放列表时解除隐藏迷你封面的引用；切歌后迟到的图片回调不能修改当前封面。主题取色仍使用最长边 96px 的缩略图，不降低本地显示图片的分辨率，但主题色可能略有变化。
* 播放列表、循环设定、智能分析、音量和高级菜单在退出动画结束后设为 `hidden`，关闭状态不参与渲染或键盘焦点。快速重开会取消旧隐藏任务，进入动画和玻璃模糊保持不变；与云音乐/下载弹窗共用背景锁定状态，不会在弹窗关闭后残留错误的 `inert`。
* 页面隐藏时暂停视觉绘制；系统启用“减少动态效果”后，流体背景和非必要动画会停用。
* 特效画布只在启停或视口尺寸改变时调整底层尺寸，连续绘制不反复分配。重新开启特效会重建画布，浏览器与驱动仍可能保留图形缓存，因此不能保证进程显存立即下降；暂停播放但仍选中特效时保持原有视觉行为。
* 取消共享请求仅解除本页面的订阅，其他使用者仍可继续；所有订阅者取消后，立即移除旧任务，重新进入页面会发起新请求。
* 缺失的歌曲封面和详情在后台补全，不阻塞音频加载。切歌后，旧详情请求不能修改新歌曲；拖动进度条也只作用于开始拖动时的曲目。
* 扫码状态串行轮询，关闭面板、切换页面、刷新二维码或退出会取消旧扫码会话和延迟返回。下载窗口音质探测最多同时进行两项，关闭后不再继续请求兜底链接；已点击启动的下载不受影响。
* 歌词时间匹配使用索引，顺序播放使用行游标，跳转和循环回跳重新定位；保留原有时间容差与逐字歌词规则。Debug 面板保留最近 1000 条日志，隐藏时不自动滚动。

### 播放模式与循环优先级

* **列表循环 / 随机播放**：歌曲播放到文件末尾后切换曲目。
* **单曲循环**：使用已解码的 `AudioBuffer` 在音频线程内直接从文件末尾回到 0，不重新下载、读取或解码歌曲。
* **A/B 循环优先**：开启循环设定或导入 `.sli` 后，自定义 A/B 点优先于单曲循环。A 点之前的前奏可以先播放一次，之后按 `B → A` 持续循环。
* **文件接缝说明**：播放器不会在循环边界额外插入停顿，但如果音频文件本身首尾带有静音、编码填充或波形不连续，这些内容仍会被原样播放。

### 方式三：智能循环制作

1. 点击 **「🔍 智能分析」** (移动端在高级菜单中)。
2. 播放到循环起点，点击 `📍 定位 A`；播放到终点，点击 `📍 定位 B`。
3. 选择匹配算法并点击 `✨ 开始精确匹配`，查看评分后试听候选接缝；不合适时调整 A/B 点再试。
4. 确认当前循环区间后，点击 `💾 导出 .sli` 导出循环点。

## 📦 部署说明

本项目为纯静态页面，但网易云功能及下载代理功能依赖后端 API。

### 1. 静态页面托管

发布版本可从 [Releases](https://github.com/minori0721/Aurora-player/releases) 下载 `index.html`，直接打开或上传到静态主机。播放器所需的两个固定版本前端库已经内嵌，不需要额外上传 JS、CSS 或 Worker 文件。

从源码部署时，使用 Node.js 22 或 24，在仓库目录运行：

```sh
npm ci
npm run build
```

产物为 `dist/index.html`。`dist/` 不提交到 Git，日常修改 `src/`，不要手动修改构建产物。

以下方式都支持从 GitHub 仓库构建。连接 Cloudflare 或 Vercel 时选择包含当前源码的部署分支，根目录保持仓库根目录，不要选 `src/` 或 `dist/`。

| 平台 | 首次设置 |
| --- | --- |
| [Cloudflare Workers（新项目推荐）](https://developers.cloudflare.com/workers/ci-cd/builds/configuration/) | 构建命令填 `npm run build`，部署命令保持 `npx wrangler deploy`；项目名称使用 `aurora-player`，发布目录由 `wrangler.json` 读取 |
| [Vercel（Other）](https://vercel.com/docs/project-configuration/vercel-json) | 安装、构建和输出目录由 `vercel.json` 读取，无需手动覆盖 |
| [Cloudflare Pages（已有项目可继续使用）](https://developers.cloudflare.com/pages/configuration/build-configuration/) | 框架选 `None`，构建命令填 `npm run build`，输出目录填 `dist` |
| [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) | 仓库 `Settings → Pages → Build and deployment → Source` 选择 `GitHub Actions`，使用已提供的 `pages.yml`，不要再创建一份模板工作流 |

Cloudflare Workers 只托管 `dist/` 静态文件，不需要编写后端 Worker。`wrangler.json` 中的名称应与平台项目名一致；使用其他项目名时同步修改该字段。首次连接后的推送由平台自动构建部署，无需重复填写参数。

Cloudflare 的 `.node-version` 已指定 Node.js 22；已有项目若手动设置了版本，请确认没有覆盖为旧版本。Wrangler 本地部署会先执行配置中的构建命令，但 **Workers Builds 不执行这项自定义构建配置**，所以面板的构建命令不能留空。Vercel 建议使用 Node.js 22 或 24。其他静态主机只需发布 `dist/` 内容，不需要 Node.js 运行服务。

GitHub Pages 工作流跟随 `minori0721-test-1` 分支，安装依赖并通过检查、测试和构建后，只上传 `dist/`，不发布源码或 `node_modules/`；也可在 Actions 中手动运行，其他分支和 PR 不触发站点部署。换用其他发布分支时，同步修改 `.github/workflows/pages.yml` 的 `push.branches` 和 `jobs.build.if`；若 `github-pages` 环境设置了分支限制，也需允许该分支。站点使用 Hash 路由与内联资源，部署到 `/Aurora-player/` 这样的仓库子路径不需要另外配置资源前缀。

已有 Pages 站点要先切换为 `GitHub Actions` 发布来源，再推送这次结构调整；继续发布分支根目录无法构建新的播放器。若要更换公开 API 地址，在仓库 `Settings → Secrets and variables → Actions → Variables` 添加 `API_BASE_URL`、`DOWNLOAD_PROXY_URL`；不设置时使用默认地址。修改变量后重新运行 Pages 工作流即可，不需要个人 Token。网页部署与下方的版本 Release 工作流互不替代。

### 2. 后端 API 配置 (重要)

推荐在部署平台设置构建期环境变量，或调整 `scripts/config.mjs` 的默认值后重新构建。下载的单文件也保留了头部配置，可按部署环境直接修改：

```html
<script>
    // 全局 API 地址 (网易云音乐 API)
    window.API_BASE_URL = 'https://musicproxy.minori.eu.cc';
    
    // 下载代理 Worker 地址 (用于绕过 Referer 限制下载音频)
    window.DOWNLOAD_PROXY_URL = 'https://proxy.minori0721.dpdns.org';
</script>

```

* **API_BASE_URL**: 使用兼容 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced/) 的 API 服务；本项目使用的 Fork 为 [minori0721/api-enhanced](https://github.com/minori0721/api-enhanced)。
* **DOWNLOAD_PROXY_URL**: 需要一个简单的 Cloudflare Worker 或 Nginx 反代，用于处理跨域和 Referer 头，以便浏览器能触发文件下载。

构建脚本会读取以下两个环境变量并注入到生成的 HTML，无需再添加替换脚本：

* `API_BASE_URL`: 网易云音乐 API 地址。
* `DOWNLOAD_PROXY_URL`: 下载代理 Worker / 反代地址。

注意：这是构建期配置，修改后需要重新部署；Cloudflare Workers 要填在构建变量中，只设置运行时 Variables / Secrets 不会改变页面。浏览器运行时不能读取平台环境变量。两个地址都会出现在公开的 HTML 中，不能填入 Cookie、Token 或其他密钥。构建脚本不会将其他环境变量打包进页面。

### 3. 后端部署平台

**推荐：[Vercel](https://vercel.com/) + 自定义域名。** `api-enhanced` 提供 Vercel 部署配置，可以从 Fork 的仓库直接导入部署。

## 🎯 算法细节

### 本地文件与 SLI 配对

本地文件导入采用“完整扫描 → 路径规范化 → 配对 → 解析 → 播放时应用”的流程。文件路径会统一分隔符、扩展名大小写和 Unicode 表示形式，并按以下顺序匹配：

1. 同目录且包含完整音频文件名，例如 `foo.wav` 对应 `foo.wav.sli`。
2. 同目录且基础名相同，例如 `foo.wav` 对应 `foo.sli`。
3. 跨目录回退仅在基础名全局唯一时使用；出现多个同级候选时标记为歧义，不自动猜测。

SLI 中的采样点会先保存到对应曲目，等音频解码并取得真实时长后再应用。换算规则保持为 `Start A = To / Base Rate`、`End B = From / Base Rate`；无 SLI、格式无效或超出音频时长的曲目不会继承上一首的循环状态。

`Base Rate (Hz)` 默认为 `44100`，用于 SLI 导入应用和导出时的采样点/秒换算，不是音频重采样或播放速度设置，应与循环点所依据的采样率一致。当前解析器只读取首个 `From` 和 `To` 数值，不支持执行复杂 SLI 脚本；导入目录里的 PNG 等独立图片也不会自动作为封面。

### 循环点匹配 (Loop Matching)

智能循环匹配提供三档策略：

1. **速度优先**：保留旧版快速 MSE 匹配逻辑，适合 A/B 点已经比较准的场景。
2. **均衡推荐**：默认档，使用低采样率 NCC 粗筛，再回到原采样率进行接缝评分与精修。
3. **准确优先**：使用更全面的候选筛选与精修流程，通常耗时更长，仍不能保证每次都找到合适接缝。

评分会综合接缝前后波形相似度、跳变误差、循环长度偏差、粗点距离和风险项。部分满足低风险条件的临界候选会小幅上调评分，影响候选排序与自动应用阈值；这不能直接视为准确率提升的证明。

### 置信度 (Confidence)

算法会返回一个用于筛选候选的置信度评分，不是经过统计校准的成功概率：

* `>= 80%`：高置信度，自动应用并显示“找到了”。
* `30% <= 评分 < 80%`：候选结果，自动应用但建议先试听确认。
* `< 30%`：不可靠结果，不自动应用，建议重新靠近 A/B 粗点。
