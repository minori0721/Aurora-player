# 技术说明

[项目首页](../README.md) · [使用指南](usage.md) · [源码结构](architecture.md)

本文记录播放、预取、循环、歌词、渲染与缓存的实现机制和参数。日常操作见 [使用指南](usage.md)。

## 双播放引擎

本地文件和在线完整加载使用 Web Audio 的 `AudioBuffer`；在线流式由原生音频元素渐进播放，经 `MediaElementAudioSourceNode` 接入音量与分析节点。

未保存偏好或偏好不可读时默认流式优先，已明确选择完整加载时保留原设置。设置只影响后续在线播放。单曲循环已启用时，在线选歌直接走完整加载；流式播放中再请求精确功能时按需准备完整 PCM。

### 生命周期与完整准备

- 暂停保留当前原生播放实例，继续播放时复用。
- 选择下一首时释放上一首实例、音频节点和自有 Blob URL，并取消旧加载。
- 原生缓冲由浏览器管理；拖动到已回收区域时可能再次请求音频。
- 完整预取字节可通过 Blob 交给原生引擎播放；切换偏好时接管兼容的在途下载。
- 精确循环、试听、智能分析和完整加载兜底优先复用自有完整文件；只有原生缓冲时，可能再次请求整首。
- 同一曲目的完整准备任务共享，完成后保留当前 PCM，供重复分析和循环复用。
- 切换引擎时读取最新进度与播放意图，并校验当前曲目和操作版本。

A/B 在完整音频准备完成并通过区间校验后启用。改动循环输入、取消设定或切换播放模式会使旧操作失效；分析试听的停止回调同样校验曲目、音源和操作版本。

### 音质标签与内存

普通流式标签首先使用 API 的格式、采样率、码率。FLAC 位深优先从已有完整预取 Blob 的前 4 KiB 读取；否则只尝试一次 `Range: bytes=0-4095`，最多等待 3 秒。

MP3 缺少可信码率时优先复用现有编码 Blob；否则后台读取前 4 KiB，ID3 标签较大或音频帧跨过范围边界时，最多再从标签尾部读取 4 KiB，每次超时 3 秒。Info 头及一致的连续帧用于固定码率；Xing/VBRI 使用帧数、字节数与采样信息计算平均码率，平均值缺失时标记 VBR。标签更新检查播放令牌、账号代数及当前地址。

文件头探测以匿名 Range 请求读取受限的 206 正文。服务器返回 200、范围不符、正文超限、缺少受限流读取能力或探测失败时，取消探测并保留原标签。`Content-Range` 因跨域未开放时，仍按部分响应和读取上限处理。结果提交前校验当前曲目、账号和完整解码状态。

位深取自有效的 FLAC STREAMINFO；MP3/AAC 标签使用格式、码率等适用参数。完整解码后的源格式和采样率优先取自文件头。

流式播放按需准备完整音频时，使用以下内存预算：

| 数据 | 桌面通常上限 | 窄屏或低内存设备通常上限 |
| --- | --- | --- |
| 完整压缩文件 | 128 MiB | 64 MiB |
| 预计整首 PCM | 256 MiB | 128 MiB |

PCM 按时长、声道和不低于 48kHz 的采样率估算，超限时拒绝该次完整准备。页面总占用还包括浏览器缓冲、解码临时数据、分析 Worker、图片和图形资源，资源回收时机由浏览器管理。

## 超时与失败恢复

| 阶段 | 当前限制 | 处理 |
| --- | --- | --- |
| 音频 URL 解析 | 最多 30 秒 | 显示解析失败提示 |
| 流式启动，尚未取得元数据 | 连续约 10 秒无进展 | 尝试一次完整加载 |
| 取得元数据后的流式播放 | 连续约 15 秒无进展 | 尝试完整加载并保留位置 |
| 完整下载，取得可用响应前 | 最多 15 秒 | 按停滞恢复预算处理 |
| 完整下载正文 | 连续 20 秒无非空数据 | 按停滞恢复预算处理 |
| 可选音频文件头 | 每次最多 3 秒；MP3 最多两次小范围读取 | 放弃补标签，不影响播放 |

流式每秒检查一次，播放位置前进或当前缓冲增长会重置无进展计时。暂停、离线、页面隐藏或音频上下文未运行时暂停计时。明确的媒体错误立即处理；自动播放被阻止时提示用户点击播放。

完整下载的响应等待从传输任务开始计时，包含网络连接、重定向和候选地址切换。

流式每个会话最多自动进入一次完整加载兜底。完整传输中，停滞恢复和遇到 `401/403/404/410` 后重新解析 URL 各最多一次，额度由预取和正式播放共享；其他网络错误保留原缓存。完整下载持续收到数据时可继续传输，回退播放需等待整首下载与解码完成。

## 下一首与详情前瞻

预取分为音频、歌词和歌曲详情三类：

预取目标由实际播放计划提供：历史前进、临时待播、原列表下一首依次优先。内部索引变化时按曲目对象重新定位，目标相同则继续使用原任务。随机模式锁定一个实际下一首，单曲循环停用后续预取。

| 任务 | 触发与范围 |
| --- | --- |
| 本地下一首整文件预读 | 剩余约 10 秒，最多一首，不预解码 |
| 在线完整音频预取 | 通常剩余约 15 秒；不小于 16 MiB 或大小未知时约 25 秒 |
| 流式下一首 | 预取 URL 和歌词；最后约 5 秒且条件允许时预热一个原生播放元素 |
| 歌词 | 随下一首音频预取任务获取原始数据，不在 URL 提前预热时单独扩大范围 |
| 歌曲详情 | 顺序播放最多查看后续 5 个位置，连续已就绪位置不超过 2 个时补齐 |

本地和在线下一首整文件预取使用桌面 64 MiB、窄屏/低内存设备或慢速网络 32 MiB 预算。已知超限时跳过正文，在线曲目保留已解析的 URL；下载中发现超限时停止。正式播放按对应播放引擎处理。

原生下一首预热要求当前缓冲充足且正在播放；后台、省流、2G、低内存、单曲或 A/B 循环时停用。切歌时接管已预热的原生元素。

歌词预取包含接口提供的原文、翻译、罗马音和逐字数据，有正文的缓存可复用 24 小时，明确无歌词和空正文仍为 1 小时；后台不解析、不渲染。本地文件匹配到网易云歌曲后也通过同一歌词缓存入口读取。正式播放接管共享请求，失败时正常获取，不阻塞音频。

详情按歌曲 ID 共享前台与后台请求，已有详情不重复获取；随机模式只补全已锁定的下一首，单曲与自定义循环不做后续详情前瞻。所有订阅取消后立即移除旧任务，重新进入时不复用已中止任务。

### 已关联歌单的启动同步

播放列表快照保存网易云歌单来源、曲目时长和详情检查时间。恢复 UI 后发起一轮低优先级 `/playlist/detail?s=0` 检查，跳过前端旧缓存，比较完整且有序的 `trackIds`。同步结果取决于 API 返回的数据。

复用原曲目对象和已返回的 `tracks`；仅对缺失的新增 ID，以及超过 5 分钟未检查的当前/可见曲目补详情，可见范围最多 20 首，按每批最多 64 个 ID 串行请求。新增歌曲详情不完整、无权限、超时或断网时，结束本轮同步并保留原快照。普通详情前瞻和实际播放请求继续按原机制运行。

提交前检查账号代数、凭据快照、队列引用、曲目对象和顺序。后台响应不能覆盖用户换过的列表；元数据变化只更新相关行，封面地址未变不重置主封面。线上已移除的当前歌曲在播放、暂停或加载时暂留，离开后移出；若线上歌单已空，则当前曲结束或手动下一首后停止。空的关联快照仍记录版本，避免较旧的 IDB 副本恢复已删除曲目。

## 本地导入与 SLI

导入流程为完整扫描、路径规范化、配对、解析、替换列表、播放时应用。优先标准文件系统接口，回退旧目录接口时反复读取目录批次直到为空，最后才使用普通文件列表；收集完成前不逐次替换列表。导入串行，按规范路径、大小和修改时间去重。

路径统一分隔符、Unicode NFC 与匹配大小写，保留显示名称。SLI 和 LRC 共用配对基础设施，优先级为：

1. 同目录、完整音频文件名，例如 `foo.wav` 对应 `foo.wav.sli`。
2. 同目录、基础名相同，例如 `foo.wav` 对应 `foo.sli`。
3. 跨目录仅在音频和配套文件基础名都全局唯一时回退。

同一级多候选标记为歧义。同路径配套文件再次导入时替换旧文件。包含音频的新批次清理旧配套注册表；只有配套文件时合并并扫描当前整个列表。空列表暂存项只供下一批音频使用一次。

SLI 解析器读取首个 From/To 区间，保存整数采样点，校验 `To >= 0`、`From > To` 和安全整数范围。播放时清除上一首的自定义循环，再按 Base Rate 换算并结合真实时长校验：

```text
Start A = To / Base Rate
End B   = From / Base Rate
```

Base Rate 默认 44100 Hz，用于 SLI 导入和导出的秒/采样点换算。导出将秒乘回 Base Rate 并取整，验证安全整数及 `From > To >= 0`，写入 `#2.00` 头和完整 `Link` 块，使用 `Smooth=False; Condition=no; RefValue=0; CondVar=0;`；导入兼容旧版裸 From/To。循环终点允许一个来源采样点的边界误差，明显越界则拒绝。只有通过校验的区间会应用到当前曲目。

目录中的独立 PNG 等图片不自动作为封面。

## 循环与匹配算法

完整播放的单曲循环复用已解码 PCM，由音频线程按 `0 → duration` 循环；A/B 和 SLI 优先，按 `B → A` 硬切回跳。接缝效果取决于源音频和区间选择，试听时应留意静音、编码填充和波形衔接。

循环输入框显示到毫秒，内部保留完整端点精度。开关循环时复用内部值，单独编辑端点时保留另一个端点的精度。实际输入、定位按钮、曲目切换和无效区间会更新或清除对应快照。

智能分析在用户给定粗略 A/B 各前后 2 秒内找接点。先搜索重复周期，再在原采样率上精修周期，最后保持周期不变、共同移动 A/B，选择较低接缝突变的位置：

| 模式 | 方法 |
| --- | --- |
| 速度优先 | 频谱候选采用较疏网格，最多精修 12 个周期、对前 2 个周期联合选点 |
| 均衡推荐 | 中等频谱网格，最多精修 16 个周期、对前 4 个周期联合选点；默认档位 |
| 准确优先 | 更密频谱网格，最多精修 24 个周期、对前 8 个周期联合选点 |

三档共用约 4kHz 的低通降采样、FFT 归一化互相关，以及色度和频带上下文候选。候选周期去重后，在原采样率的固定比较区间精修；联合选点检查实际 `B 前一采样 → A 第一采样` 的突变、原始延续差异和音乐上下文。短重叠在有足够有效采样时参与评分。

频谱特征合并各声道功率，最终验证实际声道并取较差相关性，极弱声道可以忽略。评分综合波形相关性、接缝突变和上下文，排除静音、恒定直流等无效依据；相近周期证据几乎相同时标记为歧义。评分是启发式相似度，候选仍需试听确认节奏、混响和乐句衔接。

| 情况 | 当前行为 |
| --- | --- |
| 评分不低于 30/100，当前曲目无有效循环设置 | 自动应用候选，可还原为未启用循环 |
| 评分不低于 30/100，已有手动 A/B 或有效 SLI | 保留原设置，试听后由用户明确应用；关闭但保留区间的循环也受保护 |
| 低于 30/100 或结果区间无效 | 不应用，不覆盖原循环 |

候选保存端点、评分、身份与一组原设置，复用当前 PCM；结果显示相对粗点的 A/B 偏移、原周期与候选周期。循环配置由循环模块按播放令牌区分。应用与还原均复核播放令牌、曲目、AudioBuffer、粗点、算法档位、输入版本及循环设置，手动编辑或切歌后旧结果失效；还原保留端点精度、来源和启用状态。

试听候选在现有播放核心中临时覆盖音频节点的循环区间，复用当前 AudioBuffer，从 B 前最多 1.5 秒开始播放并跨过 B → A，约 6 秒后暂停；实际循环设置和标记不变。普通播放清除临时区间，试听停止回调同时检查任务身份、曲目、播放令牌、音源与传输版本，旧定时器不能暂停新的播放。取消或手动播放会及时恢复实际循环，不增加完整音频副本或新解码。

优先在 Worker 中分析，创建或传输失败时回退主线程，回退期间可能短暂卡顿。复制 A/B 各前后 4 秒的各声道数据，重叠区域合并，每声道最多 16 秒。同一曲目、同一组窗口切换档位时复用已传数据，窗口变化时替换。最后一个任务完成后空闲 60 秒释放 Worker，主线程回退完成后释放临时缓存；当前播放 PCM 按播放生命周期保留。44.1kHz 双声道的最大传输副本约 5.4MiB。

修改粗点、使用定位按钮、切换分析档位或手动改动循环设置，会使在途分析失效并恢复开始按钮，需要时再次点击分析。取消后当前播放和共享的完整音频准备任务继续运行。

同一粗点复用降采样和频谱特征，精修按所选档位执行。44.1kHz 双声道场景的主要临时 TypedArray 约 4.5MiB，此外还有频谱缓存、FFT 内部数组和运行时开销。

面板耗时包含局部数据准备、Worker 启动与往返及匹配，不包含此前完整音频下载和解码。测试覆盖三档、反相立体声、低音量、静音、直流、周期歧义、文件边界、采样率、窗口复用、切歌取消、候选保护与还原、试听定时器和 SLI 格式往返。

## 歌词时间与排版

本地来源优先级为配套 LRC、内嵌歌词、启用后的在线搜索。本地匹配先向 `/search/match` 提供标题、专辑、歌手与秒级时长，按文本与时长筛选候选；没有候选或失败时回退 `/cloudsearch`。

解析支持 LRC、元信息 JSON 和两字段/三字段 YRC。`lyrics/timeline.js` 统一生成主歌词行和附属文本：完整相同文本按字符覆盖关系对应分行，其他情况以有序文本锚点、局部匹配及时间证据确认片段关系；无法可靠匹配时保留普通歌词。合并同句片段时沿用原文、逐字节点和时间。作词、作曲等信息与演唱行分开，翻译和罗马音附着到已有主歌词行。

翻译和罗马音优先使用能对齐的 `ytlrc/yromalrc`，缺失或版本不同则回退普通附属歌词。同一主行对应多条附属内容时保留来源关系并合并展示，切换显示档位复用已生成的时间轴。

歌词使用时间索引，顺序播放沿游标更新，跳转和循环回跳重新定位。逐字动画跟随音频时钟，只维护当前可见行，暂停、页面隐藏、音频挂起或移出视口后停止，恢复后按当前时间继续。

原文按高亮最大字号预留宽度，用内部缩放区分当前行，只有当前原文加粗，翻译和注音保持较轻字重。长词与逐字片段按可用宽度折行，沿用原时间数据。

含中日韩文字的长句按空格、全角空格和逗号、句号等标点尝试短语分组，连续结束标点及右引号留在前段，数字之间的半角或全角冒号保留连接。整句线性扫描生成基础边界，再识别连续拉丁词组。每句最多生成两套分组：优先保留连续拉丁词组，备用方案允许按普通空格拆分；基础边界复用，相同结果去重。原文在普通与高亮两种字重下分别比较自然排版，选择高度不增加、横向不溢出的方案，否则保留自然折行。显式换行、双向文字、过长文本、纯英文和罗马音使用浏览器原生断行。

NBSP（`U+00A0`）和窄 NBSP（`U+202F`）保留原字符及局部连接关系；其他普通空格、全角空格或标点仍可参与分组。这类句子只使用保留连续拉丁词组的方案，无法兼顾时回退自然排版；超长内容使用原生应急折行。

短语处理按当前或浏览行的原始顺序查找附近候选，每次最多测量 16 个文本块。重复内容按文字、宽度、字形和逐字节点结构复用结果，缓存最多 128 项；单首最多登记 1024 个块、32000 个字符。窗口宽度或字体改变后重新验证，测量副本当次移除，切歌清理记录。YRC 分组沿用已有时间节点；边界落在节点内部时合并分组或保留原排版。

滚动、缩放和附属行间距由同一个短时动画帧控制器协调，正常滚动约 400ms，跟随目标提前约 15ms 切到下一行，但实际高亮仍按音频时间。快速换句保留同方向速度衔接，结束后停止更新。手动浏览、暂停和减少动态效果时不预启动跟随滚动。

手机端的跟随锚点为歌词区高度的一半减去 `min(28px, 高度 × 15%)`。锚点按实际视口高度计算，为下一句留出空间；切换文本模式沿用同一位置，视口尺寸改变时重算。桌面按封面中心对齐。

手动浏览首次接管时取消跟随，手势停止后合并处理待更新的布局和短语分组。浏览提示复用时间索引，仅在行变化时更新文字。原生 scrollend 与 180ms 静止兜底共用结束入口，并等待手指释放。显式返回使用原生平滑滚动，期间由返回任务控制位置；新手势、切歌或隐藏页面会取消旧返回，结束后校正到最新播放行。减少动态效果时立即定位，自动返回为 6 秒。

点击歌词先通过统一 seek 入口同步提交时间，需要开始播放时再复用现有播放入口，保留点选后播放的行为。高亮读取实际生效时间，包括循环归一化后的时间；跳转失败不切换到错误的目标句。点选期间合并位置更新，重排只更新几何，最后发起一次定位；原生滚动结束还会校验是否抵达目标，避免取消旧动画产生的 scrollend 提前终止新动画。

## 系统媒体控制

Media Session 的播放、暂停、上下首、快进退和指定位置跳转共用播放器控制入口，流式与完整播放均上报实际时长和当前进度。控制回调只注册一次；播放时每秒校正进度，暂停、停滞、音频上下文挂起或切歌后停止旧计时，后台计时仍可能受浏览器节流影响。

系统媒体卡片的显示及可用操作由浏览器和操作系统决定。

## 背景、封面与渲染

当前空间背景从封面采样 `64×64` 的颜色分布，使用三轮可分离加权模糊，半径为 **3.5**，最外层样本按小数半径加权。Oklab 调整亮度与彩度，降低黑白区域的支配程度；纯灰度保留中性，全黑与全白分别映射到约 175 和 230 的灰度。

空间色场由低分辨率 WebGL 网格缓慢变形，保留颜色大致方位，按窗口比例铺满。背景画布在桌面长边不超过 512px、目标 30fps，窄屏不超过 384px、目标 24fps；界面和封面独立渲染。

颜色约 1 秒过渡，连续切歌从当前混合结果继续；窗口缩放保留流动计时，同地址或采样完全相同的封面复用结果。主题缓存最多 16 项，保存计算结果和小尺寸采样。封面变化时上传纹理，每帧更新变形和混合参数。

封面待定时暂留现有背景，确认缺失、失败或单次读取超过 15 秒后回默认色，仍属于当前曲目的迟到结果可以接上。Worker、OffscreenCanvas、WebGL 不可用或上下文丢失时，使用 ColorThief 配色的静态渐变。暂停、页面隐藏或启用减少动态效果时停止流动。

无封面时以默认蓝紫配色生成并缓存 `64×64` 渐变色场，连续无封面歌曲复用纹理和过渡。纯白、纯黑封面使用实际封面数据。主封面加载成功后隐藏并暂停默认唱片，缺失或加载失败时恢复占位；封面容器统一裁剪边界。

主封面由主图、迷你播放器与 Media Session 共用地址。网易云图片按显示尺寸与 DPR 选择 512/768/1024/1536/2048px 缩略图，窗口变化后延迟更新，GIF/APNG/WebP 扩展名保留原地址。本地封面使用原始 Blob，主题取色使用最长边 96px 的缩略图，空间背景再生成前述色场。

主封面复用两个图片元素，新图在 `decode()` 就绪后与背景同时提交，使用 400ms 原生透明度动画。过渡期间隔离图片并用 `plus-lighter` 混合，不支持时直接替换。结束后清理动画、混合状态和旧图片地址。相同地址和缩略图升级直接更新；快速切换合并到最新目标，隐藏页面或减少动态效果立即结束动画。

图片待定时旧封面最多显示 2 秒，背景沿用前述 15 秒待定策略；当前曲目的迟到图片仍可接上。切换请求立即更新主图引用、迷你封面和 Media Session，旧图仅用于视觉过渡。所有消费者和过渡解除引用后释放旧 Blob URL。

云音乐搜索、曲目、专辑、歌手、MV 和“我的歌单”的缩略图由面板观察器按滚动容器及前后约 240px 触发加载。失败立即显示占位，可见时等待 600ms 后沿用原地址重试一次；滚出视口、关闭面板、隐藏页面或替换内容会取消重试等待，已开始的原生图片下载继续交给浏览器处理。迷你封面复用相同地址，切换曲目时同步更新文字、按钮和封面引用。

云音乐弹窗按标题栏、可收缩滚动区、迷你播放器纵向排布。迷你播放器按实际高度占位，隐藏时释放空间；滚动区使用普通内边距和安全区。

播放列表序号按整张歌单最大编号的位数统一列宽，至少预留三位；使用等宽数字、右对齐与固定序号字重，保持选中和未选中行的封面对齐。后台追加或替换歌单时更新共享列宽。

列表搜索缓存每首歌已有的规范化搜索文本，使用 NFKC、大小写折叠和多词包含匹配；输入法组词完成后筛选。筛选通过现有行的 hidden 状态控制显示，原队列和持久化数据保持原样。追加与单首详情更新增量处理，过滤变化通知封面调度器重算附近集合。超过 500 首时，在支持的浏览器上使用 content-visibility 跳过离屏行内部排版，预留内容高度取 30px 封面与文字行高的较大者；不支持时保留普通列表。

列表封面由独立调度器跟踪当前可见区域及前后约 300px，滚动时重新排序并移出远处尚未开始的任务。并发上限 4，附近预加载最多占 2 个名额；可见图片立即安排，附近预加载在停止滚动约 120ms 后补齐。调度按观察器维护的附近集合及任务完成事件推进。

已经开始的离屏小图通常继续完成。只有当前可见任务被堵住、旧请求已离开预加载范围、运行超过约 500ms 且滚动已稳定时，才回收远处请求；每轮稳定窗口最多回收 2 个。主动取消独立于失败，及时释放名额，不增加重试次数；超时会停止旧请求。单次超时仍为 8 秒，失败最多重试 2 次，连续失败冷却 30 秒，仅可见区域自动重试。

相同封面共享请求，成功状态和失败冷却使用最多约 300 项的缓存。图片接近视口后建立资源任务，使用固定尺寸占位。关闭列表或隐藏页面停止新任务及重试调度，在途结果可以完成并供重开时复用；替换歌单时取消旧任务，回调提交前校验归属。主封面和迷你封面解除引用后释放旧 Blob URL。

普通播放低频更新时间，逐字与换句使用各自必要调度，特效开启时持续绘制。暂停且关闭特效、过渡完成后停止 RAF；无特效按需清空画布。特效停用、隐藏或减少动态效果时画布退出合成并缩为 `1×1`，恢复前重建。

移动端首屏播放器以 `100dvh` 分配高度，播放控件保持尺寸，歌词占剩余空间；封面沿用宽度上限并通过 `svh` 限制短屏尺寸。版本区位于首屏之后，短横屏使用双列，内容超出窗口时允许整页滚动。特效按可视窗口大小绘制，频谱基准在画布底边。

## API、账号与缓存

### 内容与歌单

- 歌单使用 `/playlist/detail` 的完整 `trackIds` 决定顺序，再分批调用 `/song/detail`，首批可先播放。取消保留已加载部分，权限、缺失项和批次失败仍可能造成不完整列表。
- 我的歌单使用 `/user/playlist` 的 `more/limit/offset` 分页，并按 ID 去重。
- 歌手概览优先 `/artists` 一次取信息与热门歌曲，缺字段时回退 `/artist/detail`、`/artist/top/song`；概览预取专辑和 MV 前 30 项、展示前 6 项，标签首页复用缓存。
- 同一实体切标签共享在途请求，单项失败只重试该项；切实体取消旧导航，迟到结果不能覆盖新页。
- 导入页保留当前预览页的 DOM 与播放上下文引用，重新进入时恢复有效关联，替换或清空列表时解除旧关联。全局上下文最多 24 项，缺失关联的播放操作记录警告。
- `/song/music/detail` 在打开下载窗口时按需读取，下载接口和 match 结果确认实际可用音源。
- 格式取自实际音源 URL 的文件后缀或 API 类型，已有字节可补充解析文件头。下载页使用已有信息，未知类型显示“格式未知”，下载文件名省略扩展名；官方参数在实际返回档位一致时补充，match 参数取自实际匹配音源。
- 内容浏览覆盖歌曲、专辑、歌手和官方 MV 外链。

### 缓存与凭据

公共搜索、专辑、歌手等数据可进入 IndexedDB `metadata`；URL 含 `cookie/token/key` 时只用账号内存缓存，登录状态、二维码和账号修改不使用公共缓存，强制刷新跳过缓存读取。公共键移除 `timestamp/noCache` 等瞬态参数，启动迁移和退出登录清理旧敏感键。

公开 JSON 和账号 JSON 的内存缓存分别保留最多 200 条、16MiB 序列化正文预算，超限按最近使用淘汰。公共 IndexedDB 缓存保留最多 200 条、7 天，并以 64MiB 正文预算批量清理，每 20 次写入或累计写入 4MiB 后安排一次清理，短时可能超过预算。单条超出磁盘预算时跳过持久化。大小在写入或旧记录首次读取时计算并计入预算。`player-state`、列表备用快照、偏好和登录凭据单独保存。

仅公开专辑、歌手资料及其栏目、歌词显式允许过期内容优先返回。新鲜数据不发请求，过期且写入未超过 7 天时按需更新缓存，同一键合并在途任务；搜索、音频链接、账号状态和带凭据请求不启用此策略。后台结果不重绘当前页面或替换正在显示的歌词、播放队列，下次载入使用新结果。专辑和歌手公开资料的新鲜期仍为 30 分钟，搜索仍为 5 分钟。

更新按需进入空闲请求队列，正文读取期间持续占用并发槽，后台最多一个空闲槽；总等待上限 12 秒，失败保留原成功数据并冷却 5 分钟。离开页面时取消尚未发出的任务，已经发出的公开请求允许完成并缓存，重新进入接管同一任务。手动刷新可接管在途请求或绕过冷却，成功后替换原缓存。

已解析音频链接内存最多 200 项，保存 URL 及解析信息；插入时清理过期项，访问命中优先保留，淘汰后重新解析。

`/song/url/match` 以匿名请求发送歌曲 ID、来源等公开参数，复用短时公共缓存和在途请求；官方音频接口按账号隔离。匹配来源的网络错误、异常响应和 5xx 失败，会让同一歌曲、音质、账号会话和来源的后台尝试暂缓 30 秒，主动播放仍可重试。明确的 429 对主动与后台请求均遵守可读的 `Retry-After`，缺少有效等待时间时使用 30 秒。失败记录按上述维度在内存保存，最多 200 项，退出或清理音频链接缓存时清除；主动取消直接结束任务。

匹配失败记录来源、HTTP 状态、接口错误码和失败类别，播放与下载区分来源故障和暂无完整资源。应用内日志在写入控制台和日志面板前脱敏；浏览器网络日志和扩展日志由各自组件生成，分享前需检查凭据。

登录凭据读取、登录成功与发送前使用同一规范化规则，过滤空片段及 Set-Cookie 属性，同名字段保留最后一项，保留未知名称和值中的等号；旧 localStorage 记录在启动时按需更新。除登录相关 POST 外，依赖账号的 GET 仍可能在 URL 中携带 Cookie，导出或分享浏览器日志前应遮住凭据。

扫码串行轮询，短信通过 `/captcha/sent/v1` 发送、`/login/cellphone` 登录。手机号、验证码和校验凭据放 POST 正文，不写缓存或日志；登录凭据保存在当前站点 localStorage，用于恢复账号。

短信默认间隔 60 秒，服务器可读的更长 `Retry-After` 优先；倒计时在当前页面内存保存，不跨刷新。账号校验和会员查询独立，15 秒超时覆盖正文，会员失败不阻塞已确认的登录。关闭登录、切方式、刷新二维码或退出会取消旧任务；临时账号校验失败只重试校验，不自动重新发短信。

账号提交前检查代数与凭据快照，旧响应不能恢复已退出账号或覆盖后来的音质选择。下载窗口音质探测最多两项并发，关闭后不继续请求兜底链接，已启动的下载不撤回。

### 恢复与异步边界

播放列表以结构化字段保存在 IndexedDB `player-state`，本地存储保留无句柄的轻量备用快照，兼容旧 schema 2 和旧快照迁移。列表和选中位置用同一事务读写，内容变化时保存完整快照，选中位置携带列表身份与内容版本。

原列表与临时点播分开保存：`tracks` 和选中位置描述原列表，`manual.current/pending` 描述当前临时曲目和待播。音频正文、PCM 及前进/后退历史随当前页面会话管理。播放投影复用曲目对象，历史最多 32 项，临时条目变化时增量更新对应行；来源同步只比较原列表。

恢复时按路径、大小和修改时间补回唯一匹配的文件句柄。本地音频和伴随文件正文由用户文件提供；存储被禁用、写满或进程被强制终止时，最后一次保存可能失败。

持久化遇到含文件句柄状态的 `DataCloneError` 时，创建无句柄副本重试一次；权限、配额等错误直接报告失败，保留已有轻量备用快照。歌单来源绑定时校验一次完整结构，后续通过原列表引用和结构版本查询。

内部播放状态只接受既定状态名，错误的内部调用直接报错；外部网络与解码错误进入正常错误状态。歌词意外异常每轮渲染只报告一次并停止该轮更新，切歌或重建歌词后恢复，音频继续播放。异步歌词任务独立捕获异常。

本地读取、解码、歌词、封面、歌单和在线请求分别校验当前播放令牌、曲目身份、导航令牌或账号代数。取消共享请求只解除当前订阅，其他使用者仍可继续；没有订阅者的任务及时移除，避免下次复用已中止请求。

播放列表、循环、分析、音量和高级面板在退出动画结束后设为 `hidden`；快速重开撤销旧隐藏任务，与模态窗口共用背景锁定。日志面板仅保留最近 1000 条日志，隐藏时不自动滚动。

桌面顶部自动收起使用一个约 4 秒的截止时间定时器，没有额外 RAF。仅播放且页面可见时计时，悬停、键盘焦点、原生选择器和打开的面板保持可见；收起后设置 `inert`，输入事件先恢复再由浏览器处理。控制器只撤销自己施加的 `inert`，不覆盖模态窗口的背景锁定。窄屏和无悬停设备不自动收起。
