# 使用指南

[项目首页](../README.md) · [部署指南](deployment.md) · [技术说明](technical.md)

## 本地文件与文件夹

将 MP3、FLAC、OGG、WAV、M4A 等音频文件拖入窗口，或使用「导入」选择文件。能否播放取决于文件实际编码与浏览器，不仅取决于扩展名。

导入整个文件夹时，会递归扫描子目录，保留相对路径，完成后一次性生成播放列表。浏览器不能展开目录时，会提示改为选择目录内文件。

导入批次按以下规则处理：

- 包含音频：替换当前播放列表，只使用本批次的音频与配套文件；空列表之前暂存的配套文件可供下一批音频尝试匹配一次。
- 只有 `.sli` / `.lrc`：补充当前列表，并重新检查所有歌曲的配对，不只处理当前歌曲。
- 空列表先导入配套文件：暂存到下一批本地音频，不会一直跨专辑沿用未匹配项。

SLI 成功匹配后，播放列表会显示 `∞` 标记。导入汇总会列出音频、SLI、匹配、未匹配、歧义和无效数量；歧义或无效项不会自动启用循环。详细配对规则见 [技术说明](technical.md)。

本地歌词依次使用配套 LRC、内嵌歌词、启用后的在线搜索结果。后补 LRC 时会重新检查优先级，不需要重新导入全部音频。

## 关闭页面后的恢复

播放器保存曲目信息、顺序和当前索引，不把本地音频文件复制成离线曲库。

- 支持文件句柄且文件仍可访问时，点击播放可请求读取授权；已有授权时可直接读取，后台切歌不会主动弹出授权框。
- 浏览器不支持、句柄丢失或文件不可访问时，需要重新选择文件。
- SLI/LRC 正文不随播放列表保存，重新打开后需要补充配套文件；恢复的目录与文件名仍用于安全配对。
- 浏览器存储按来源隔离，更换域名、开发端口或本地 HTML 路径后，可能看不到原来的恢复记录；构建不会清理旧数据。
- 清除站点数据、存储被禁用、空间不足或进程被强制结束，都可能影响最后一次保存。

## 网易云搜索与浏览

1. 点击「云音乐」打开内容浏览器。
2. 搜索后可切换「综合 / 歌曲 / 专辑 / 歌手」。
3. 点击歌曲播放，点击歌手名或专辑封面进入对应页面。专辑和歌手页面也可以继续互相跳转。
4. 从某个页面播放时，使用该页面对应的歌曲建立队列；分页列表通常只使用当前页，并非歌手全部作品。

专辑页提供曲目、顺序/随机播放和收藏。歌手页提供简介、热门歌曲、全部歌曲、专辑/EP、MV 和关注；MV 打开网易云官方页面，不加入 Aurora 的音频队列。

面板内支持返回和前进，地址中的 `#music/...` 可以刷新或直接打开。根页返回按钮只关闭面板；关闭不会停止播放，再次打开恢复最后浏览位置。底部迷你播放器可控制播放，点击主体返回主播放页。

## 播放方式

在云音乐面板的「播放」选择器中设置：

| 选项 | 行为 |
| --- | --- |
| 流式优先 | 浏览器原生渐进播放，不必等整首文件下载完；失败时尝试一次完整加载 |
| 完整加载 | 下载并解码完整音频后播放，适合希望任意跳转和精确循环的场景 |

未设置过偏好时默认流式优先，已有明确选择会保留。修改设置影响后续在线播放，不会立即切换当前歌曲；本地文件仍使用完整解码。

进度条附近的「流式播放 / 完整播放」表示当前引擎，不代表一定仍有网络请求，也不表示永久缓存。浏览器可以回收原生流式缓冲，之后跳转可能需要重新请求。

流式 FLAC 可根据文件头补全位深；MP3/AAC 不显示与无损 PCM 同义的源位深。无法取得可靠信息时保留 API 已提供的标签，不猜测 `16bit/24bit`。

## 歌单导入与账号

在「导入歌单」粘贴网易云歌单链接或 ID。首批歌曲加载后即可先导入播放，剩余歌曲按原顺序后台补齐，界面显示已加载数量；过程中可以取消。

「我的歌单」需要登录，首批显示后继续分页加载。取消加载或退出账号会保留已经导入的歌曲，不强制切歌；再次替换歌单后，旧请求不能追加到新列表。

登录支持 APP 扫码和手机短信验证码。首次打开时桌面默认扫码、窄屏默认验证码，同一次页面会话保留手动选择的方式。验证码可修改国家区号，发送冷却期间不能重复发送；发送超时也可能已经发出短信，不会自动重发，收到后仍可尝试输入登录。

登录后可以读取账号歌单、收藏专辑和关注歌手，但登录不等于获得 VIP 权益。网易安全验证、限流、歌曲版权与 API 状态都可能影响可用功能。

## 歌词

- 支持仅原文、原文加翻译、原文加罗马音；附属内容需歌词源提供。
- 支持滚轮、触摸和键盘浏览，点击带时间的歌词可跳转播放。
- 手动浏览时显示浏览时间，可点击「回到当前」；播放中停止浏览约 6 秒后恢复跟随，暂停时不强制倒计时返回。
- 长歌词可折行，当前原文加粗并放大，翻译与注音保留在下方。
- 有有效 YRC 时显示逐字高亮，没有时使用普通歌词；减少动态效果时使用较简单的逐词点亮。

## 循环设定与分析

| 模式 | 播放行为 |
| --- | --- |
| 列表循环 | 到末尾后切换下一首 |
| 随机播放 | 从当前队列选择下一首 |
| 单曲循环 | 使用完整 PCM 从文件末尾回到开头 |
| A/B 或 SLI | 自定义区间优先，前奏可播放一次，之后按 `B → A` 循环 |

流式播放中开启精确循环、试听或智能分析，会按需准备完整音频，可能重新传输并增加内存占用；准备任务会复用已有完整文件或解码结果。

不知道循环点该放在哪？试试「智能分析」：

1. 打开「智能分析」，移动端在「高级」菜单中。
2. 播放到大致起点和终点，分别定位 A、B。
3. 选择匹配策略，点击「开始匹配」。高评分时会提示「找到了」，先试听接缝，不合适时再调整粗点。
4. 确认区间后导出 `.sli`。

分析是寻找粗略 A/B 附近的接缝，不是自动识别整首歌的副歌或游戏原始循环点。评分不是成功概率；中等评分候选也会应用，仍需试听。若文件本身带有静音、编码填充或不连续波形，播放器不会自动修掉这些内容。

`Base Rate (Hz)` 用于 SLI 采样点与秒的换算，不是改变音质、重采样或播放速度的设置，应与循环点的来源一致。命名、换算、算法和阈值见 [技术说明](technical.md)。

## 下载与界面控制

播放在线歌曲后，点击下载图标，选择可用音质。音质列表会按需检测，标准、较高、极高、无损和 Hi-Res 是否可用取决于接口、账号与音源，不保证每首都有全部选项。下载代理需单独配置。

特效保留「凛冬飞雪」「律动频谱」「极光波浪」：飞雪会随低音鼓点加速，频谱和波浪跟随音乐变化。想清静一点就选「无特效」，也就是原来的「纯净模式」；封面配色背景仍会在播放时缓慢流动。

移动端顶部保留「导入」「高级」长条按钮，云音乐、下载和播放列表使用图标按钮；智能分析、循环设定、特效和 Debug 在高级菜单中。

| 按键 | 动作 |
| --- | --- |
| Space | 播放 / 暂停 |
| 左 / 右方向键 | 快退 / 快进 |
| 上 / 下方向键 | 调节音量 |
| Enter / Space | 激活已聚焦的播放列表按钮 |
| Escape | 关闭当前模态窗口 |

全局快捷键仅在页面非交互区域生效。输入框、按钮、选择器、进度条、链接、可编辑内容和弹层保留原生键盘行为。云音乐与下载窗口会限制 Tab 焦点、锁定背景，关闭后恢复原焦点。

## 常见问题

- **显示流式但拖动仍要加载**：缓冲不永久保留，且服务器可能需要额外范围请求；需要完整音频时可切换完整加载后重新选歌。
- **流式 FLAC 没有位深**：可选文件头探测可能被跨域、超时或范围读取能力限制，不代表音质被降低。
- **第一次点击没有声音**：部分浏览器需要用户操作才能解锁音频，或会挂起后台音频；点击播放重试，不保证所有设备锁屏后台行为一致。
- **歌单数量少于总数**：可能仍在后台加载，也可能有接口权限、缺失歌曲或批次失败；查看加载状态与提示。
- **SLI 不生效**：检查配对状态、文件语法、Base Rate 与音频时长；解析器只读取首个 From/To，不执行复杂 SLI 脚本。
- **搜索正常但音频很慢**：获取 URL 的 API 与音频 CDN 是不同链路。排查时看音频 GET 的状态和 Timing，不要只看搜索接口。

更详细的生命周期、限制与隐私说明见 [技术说明](technical.md)。
