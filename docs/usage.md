# 使用指南

[项目首页](../README.md) · [部署指南](deployment.md) · [技术说明](technical.md)

## 本地文件与文件夹

将 MP3、FLAC、OGG、WAV、M4A 等音频文件拖入窗口，或使用「导入」选择文件。文件实际编码需受当前浏览器支持。

Android 浏览器支持时优先打开系统文件选择器，可同时选择音频、LRC 和 SLI，选择后自动识别文件类型。取消选择保留当前播放和列表；若提示选择器不可用，再次点击「导入」使用兼容方式。导入已有文件使用文件读取权限。

导入整个文件夹时，会递归扫描子目录，保留相对路径，完成后一次性生成播放列表。浏览器不能展开目录时，会提示改为选择目录内文件。

导入批次按以下规则处理：

- 包含音频：替换当前播放列表，只使用本批次的音频与配套文件；空列表之前暂存的配套文件可供下一批音频尝试匹配一次。
- 只有 `.sli` / `.lrc`：补充当前列表，并重新检查整张列表的配对。
- 空列表先导入配套文件：暂存并供下一批本地音频匹配一次。

SLI 成功匹配后，播放列表会显示 `∞` 标记。导入汇总会列出音频、SLI、匹配、未匹配、歧义和无效数量；歧义或无效项不会自动启用循环。详细配对规则见 [技术说明](technical.md)。

本地歌词依次使用配套 LRC、内嵌歌词、启用后的在线搜索结果。后补 LRC 时会重新检查优先级，不需要重新导入全部音频。

## 关闭页面后的恢复

播放器保存曲目信息、顺序和当前索引，本地音频仍从原文件读取。

- 支持文件句柄且文件仍可访问时，点击播放可请求读取授权；已有授权时可直接读取，后台切歌不会主动弹出授权框。
- 浏览器不支持、句柄丢失或文件不可访问时，需要重新选择文件。
- SLI/LRC 正文不随播放列表保存，重新打开后需要补充配套文件；恢复的目录与文件名仍用于安全配对。
- 浏览器存储按来源隔离，更换域名、开发端口或本地 HTML 路径后，可能使用不同的恢复记录。
- 清除站点数据、存储被禁用、空间不足或进程被强制结束，都可能影响最后一次保存。

从「导入歌单」建立的网易云队列会保存来源。再次打开时先显示本地快照，再后台核对一次线上曲目顺序，补充新增歌曲，更新当前或可见歌曲的过期资料；失败时继续使用快照。未变化的资料和封面直接复用，正在播放的歌曲保持原状。线上移除的当前歌曲暂留到切歌。歌单同步仅用于已关联来源的队列；旧记录缺少来源时，重新导入一次即可关联。

公开资料和歌词另有缓存，与播放列表及设置分别保存。歌词正文通常复用 24 小时，无歌词结果复用 1 小时；部分过期静态资料先显示旧内容，再按需更新供下次使用。更新失败时保留原内容并暂缓再次更新，音频按播放引擎的生命周期管理。

## 网易云搜索与浏览

1. 点击「云音乐」打开内容浏览器。
2. 搜索后可切换「综合 / 歌曲 / 专辑 / 歌手」。
3. 点击歌曲播放，点击歌手名或专辑封面进入对应页面。专辑和歌手页面也可以继续互相跳转。
4. 单击歌曲临时点播并保留原列表；连续听页面内容可用「播放专辑 / 播放全部」或歌曲菜单的「从这首连续播放」。分页列表的连续播放范围为当前页。

专辑页提供曲目、顺序/随机播放和收藏。歌手页提供简介、热门歌曲、全部歌曲、专辑/EP、MV 和关注；MV 在网易云官方页面打开。

面板内支持返回和前进，地址中的 `#music/...` 可以刷新或直接打开。根页返回按钮只关闭面板；关闭不会停止播放，再次打开恢复最后浏览位置。底部迷你播放器可控制播放，点击主体返回主播放页。

## 原列表与临时点播

- 单击浏览页面中的歌曲立即播放，原列表和原位置保留；临时歌曲播完后继续原列表下一首。
- 歌曲右侧 `…` 可选「下一首播放」或「加入队列」；专辑的「加入队列」把整张专辑按顺序追加。临时待播优先于原列表，随机模式下也保持手动加入的顺序。
- 右侧 PLAYLIST 分别显示「临时点播」和「原播放列表」。清空临时待播保留当前播放及原列表；列表搜索同时筛选两部分。
- 「上一首」沿本次实际播放历史返回。单曲循环、A/B 与 SLI 循环仍优先，手动「下一首」可以离开单曲循环。
- 「播放专辑 / 播放全部」「从这首连续播放」和导入新列表会替换原列表；有临时待播时先确认。临时当前歌曲和待播曲目随快照恢复，历史前进/后退记录不跨页面重开保存。

临时点播保留导入歌单的来源关系，后台同步只更新原列表，不替换正在播放的临时歌曲。

加入队列后显示约 3 秒的操作提示，待播曲目可在 PLAYLIST 查看。清空临时待播、替换列表、切换云音乐页面、关闭面板或页面进入后台时清理提示。

## 播放方式

在云音乐面板的「播放」选择器中设置：

| 选项 | 行为 |
| --- | --- |
| 流式优先 | 浏览器原生渐进播放，不必等整首文件下载完；失败时尝试一次完整加载 |
| 完整加载 | 下载并解码完整音频后播放，适合希望任意跳转和精确循环的场景 |

未设置过偏好时默认流式优先，已有明确选择会保留。修改设置影响后续在线播放，不会立即切换当前歌曲；本地文件仍使用完整解码。

进度条附近的「流式播放 / 完整播放」表示当前播放方式。流式缓冲由浏览器管理，回收后跳转可能需要重新请求。

音质标签显示已确认的参数：FLAC 可根据文件头补全位深，MP3 可补全码率；详细识别方式见 [技术说明](technical.md#音质标签与内存)。

下载面板显示实际音源的格式、码率、采样率和大小，缺失参数留空；MP3 采样率沿用 API 提供的信息。

## 歌单导入与账号

在「导入歌单」粘贴网易云歌单链接或 ID。首批歌曲加载后即可先导入播放，剩余歌曲按原顺序后台补齐，界面显示已加载数量；过程中可以取消。

切换页面或关闭后重新打开云音乐时，保留的歌单预览仍可直接点播和加入队列，不需要重新获取歌单。

「我的歌单」需要登录，首批显示后继续分页加载。取消加载或退出账号会保留已经导入的歌曲，不强制切歌；再次替换歌单后，旧请求不能追加到新列表。

登录支持 APP 扫码和手机短信验证码。首次打开时桌面默认扫码、窄屏默认验证码，同一次页面会话保留手动选择的方式。验证码可修改国家区号，发送冷却期间不能重复发送；发送超时也可能已经发出短信，不会自动重发，收到后仍可尝试输入登录。

登录后可以读取账号歌单、收藏专辑和关注歌手。可用音质和功能受账号权益、歌曲版权、安全验证、限流与 API 状态影响。

备用音源暂时失败时，后台会短暂减少重复尝试；主动播放仍可重试，明确限流时按服务器要求等待。反馈问题前，请遮住请求和浏览器网络日志中的 `cookie`、Token 等凭据。

## 歌词

- 支持仅原文、原文加翻译、原文加罗马音；附属内容需歌词源提供。
- 支持滚轮、触摸和键盘浏览，点击带时间的歌词可跳转播放。
- 手动浏览时显示浏览时间，可点击「回到当前」平滑返回；再次滚动立即接管。播放中停止浏览约 6 秒后恢复跟随，暂停时不强制倒计时返回，减少动态效果时直接定位。
- 手机端的浏览时间和「回到当前」仅浏览时浮在歌词区底部，可能覆盖底部少量歌词，返回跟随后隐藏。
- 长歌词可折行，当前原文加粗并放大，翻译与注音保留在下方。
- 手机端当前原文固定在歌词区中心略上方，为下一句留出空间；切换原文、翻译和罗马音时沿用同一位置。桌面跟随封面中心。
- 中日韩长句优先在空格和标点处分组折行，保留连续英文和不换行空格的连接关系；分组会增加行数时使用自然折行。逐字歌词沿用原时间片段。
- 有有效 YRC 时显示逐字高亮，没有时使用普通歌词；减少动态效果时使用较简单的逐词点亮。
- 普通歌词与逐字歌词依据文本、顺序和时间对齐，翻译与罗马音附在对应原文下；无法可靠对应时使用普通歌词。

## 循环设定与分析

| 模式 | 播放行为 |
| --- | --- |
| 列表循环 | 到末尾后切换下一首 |
| 随机播放 | 先按顺序播放临时待播，再从原列表随机选择 |
| 单曲循环 | 使用完整 PCM 从文件末尾回到开头 |
| A/B 或 SLI | 自定义区间优先，前奏可播放一次，之后按 `B → A` 循环 |

流式播放中开启精确循环、试听或智能分析，会按需准备完整音频，可能重新传输并增加内存占用；准备任务会复用已有完整文件或解码结果。

不知道循环点该放在哪？试试「智能分析」：

1. 打开「智能分析」，移动端在「高级」菜单中。
2. 播放到大致起点和终点，分别定位 A、B。
3. 选择匹配策略，点击「开始匹配」。结果显示 A/B 偏移与周期变化；当前曲目没有有效循环设置时，可用候选会自动应用。
4. 已有手动 A/B 或有效 SLI 时保留原设置，包括暂时关闭的循环；点击「试听接缝」检查候选，再点击「应用」替换。「还原」恢复应用前的区间、启用状态与端点精度；原来没有循环时则取消此次循环。
5. 确认区间后导出 `.sli`。

分析期间调整粗点、切换策略或手动修改循环设置，会取消当前分析；需要时重新点击「开始匹配」，不会中断正在播放的音乐。循环输入框显示到毫秒，关闭再开启循环仍保留内部端点精度。

分析在粗略 A/B 附近寻找接缝，评分表示候选相似度；30 分及以上保留为可用候选，低于 30 分保留原设置。候选试听从 B 前开始，按候选 B → A 循环，约 6 秒后暂停；重新播放恢复实际设置。改点、切歌或重新分析会使旧候选与还原操作失效。建议试听确认乐句衔接及源文件中的静音或编码填充。

`Base Rate (Hz)` 是 SLI 采样点与秒的换算基准，应与循环点来源的采样率一致。命名、换算、算法和阈值见 [技术说明](technical.md)。

SLI 导出为标准 `#2.00` 与 `Link { ... }` 格式，使用 `Smooth=False` 保持硬切循环；仍可导入旧版仅含 From/To 的文件。

## 下载与界面控制

PLAYLIST 标题右侧可搜索当前播放列表已有的歌名、歌手和本地文件名，兼容大小写及全半角，多个关键词需全部匹配。

搜索仅筛选列表显示，播放顺序和原编号保持原样；右侧 `×` 或输入框中的 Escape 清空搜索条件。关闭列表保留本次搜索，替换播放列表后清空；定位到当前歌曲时，若该曲被筛掉，会先清除筛选再平滑定位。

播放在线歌曲后，点击下载图标，在检测到的可用音质中选择标准、较高、极高、无损或 Hi-Res。可用档位取决于接口、账号权益与音源；下载代理配置见 [部署指南](deployment.md#api-与下载代理地址)。

特效保留「凛冬飞雪」「律动频谱」「极光波浪」：飞雪会随低音鼓点加速，频谱和波浪跟随音乐变化。想清静一点就选「无特效」，也就是原来的「纯净模式」；封面配色背景仍会在播放时缓慢流动。

切换主封面时，新图准备好后与背景平滑过渡；相同封面和清晰度升级不重复淡入，图片加载不阻塞音频。加载失败或没有封面时恢复默认唱片，减少动态效果时直接换图。具体时序见 [技术说明](technical.md#背景封面与渲染)。

日志入口统一为「Log」，点击可显示或隐藏日志。面板提示使用中文，格式名、接口名和原始错误详情保留原样。播放方式提示对齐进度条中心，启用循环时另行显示循环标记；音质标签不在内部换行，过长时省略显示。

移动端顶部保留「导入」「高级」长条按钮，云音乐、下载和播放列表使用图标按钮；智能分析、循环设定、特效和 Log 在高级菜单中。

手机首屏优先保留底部播放按钮，歌词使用剩余高度，短屏适当缩小封面；版本和 GitHub 链接位于首屏下方，下滑查看。短横屏改为左右布局，极短窗口、很长的标题或大字体可整体滚动，不裁切控件。

桌面播放时，顶部工具栏在约 4 秒无操作后向上收起；移动鼠标、点击、按键或重新聚焦窗口即可显示。暂停、加载、出错，以及正在使用顶部控件或打开面板时保持显示。手机和触控设备顶部常驻，底部播放控制不收起；减少动态效果时不播放收起动画。

桌面顶部的云词开关、下载按钮旁的圆形歌词按钮，与移动端高级菜单共用状态。云词开关只控制本地歌曲自动匹配网易云歌词，不影响已有 LRC、内嵌歌词或在线播放歌词。「词／译／音」分别表示仅原文、原文加翻译、原文加罗马音；桌面按钮循环切换可用文本，手机使用三段选择，缺失的档位不可选。切歌和调整窗口宽度时保留偏好。手机调整这两项不会关闭菜单，点击外部或按 Escape 关闭。

| 按键 | 动作 |
| --- | --- |
| Space | 播放 / 暂停 |
| 左 / 右方向键 | 快退 / 快进 |
| 上 / 下方向键 | 调节音量 |
| Enter / Space | 激活已聚焦的播放列表按钮 |
| Escape | 关闭当前模态窗口 |

全局快捷键仅在页面非交互区域生效。输入框、按钮、选择器、进度条、链接、可编辑内容和弹层保留原生键盘行为。云音乐与下载窗口会限制 Tab 焦点、锁定背景，关闭后恢复原焦点。

## 常见问题

- **显示流式但拖动仍要加载**：缓冲不永久保留，且服务器可能需要额外范围请求；需要完整音频时可切换完整加载后重新选歌。
- **流式 FLAC 没有位深**：文件头读取可能遇到跨域、超时或范围读取限制，此时保留已确认的音质信息。
- **第一次点击没有声音**：部分浏览器需要用户操作才能解锁音频，或会挂起后台音频；回到页面点击播放重试。
- **歌单数量少于总数**：可能仍在后台加载，也可能有接口权限、缺失歌曲或批次失败；查看加载状态与提示。
- **SLI 不生效**：检查配对状态、文件语法、Base Rate 与音频时长；解析器只读取首个 From/To，不执行复杂 SLI 脚本。
- **搜索正常但音频很慢**：获取 URL 的 API 与音频 CDN 是不同链路。排查时看音频 GET 的状态和 Timing，不要只看搜索接口。

更详细的生命周期、限制与隐私说明见 [技术说明](technical.md)。
